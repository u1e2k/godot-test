# 🎮 Breakout Retro (物理ボタン・Android対応 ブロック崩し)

Godot Engine 4 (GDScript) で構築された、Android搭載ゲーム機（Anbernic RG Rotate / RG Cube / RG353 / RG405 / RG505、Retroid Pocket、Odinなど）、PC、およびスマートフォンで快適に動作する本格ブロック崩しゲームです。

**720x720 (1:1 正方形画面)** に最適化されており、10種類の個性的なステージレイアウト、動く敵ターゲット（UFOドローン）、全12種類のパワーアップアイテム、そしてXP＆レベル成長システムを搭載しています。

---

## 🚀 主な特徴

1. **720x720 (1:1) 正方形画面・RG Rotate 完全最適化**:
   - RG Rotate / RG Cube 等の正方形ディスプレイにジャストフィットする 8 列グリッド・外壁・ネオンUI設計。
   - パドルの Y 座標固定（`PADDLE_Y = 640.0`）による物理めり込み・沈み込み消失バグの根本防止。
2. **10種類の個性的なステージレイアウト**:
   - ピラミッド、ダイヤモンド金庫、スペースインベーダー、ツインタワー、キャッスル要塞、市松模様、ネオンハート、ジグザグ迷路、ドローン大要塞など多彩なステージ。
3. **動く的・ギミック（UFO / ドローンターゲット）**:
   - 画面内を左右にパトロール移動する動くターゲット。
   - 撃破すると高得点（+800点）＋大量XP（+300XP）＋**確定レアアイテムドロップ**！
4. **レベル＆XP成長システム**:
   - ブロック破壊や的撃破で経験値（XP）を獲得し、リアルタイムにレベルアップ！
   - レベルアップ特典（スコア倍率UP、パドル速度UP、ドロップ率UP、残機＋シールドボーナス等）。
   - レベルアップ時に華やかなネオンバナーと専用ファンファーレ演出。
5. **全12種類の多彩なパワーアップアイテムシステム**:
   - ブロック破壊時に約 32% の確率でアイテムカプセルがドロップ。
   - シールド、ボムボール、キャッチ、5球メガ分裂、追尾ミサイル、レーザー、貫通ファイヤーボールなど多彩な能力。
6. **洗練されたボール速度バランス**:
   - 初速 `410.0` / 最高速度 `680.0` / 加速 `+3.0` (1ヒットあたり)。
   - ラリーが長続きし、人間の反射神経でしっかり打ち返せる適正なテンポ感。
7. **Android「Bボタン問題」の完全解決**:
   - Godot の **Input Map** と **Joypad Event** を活用し、Android の戻る（Back）キー競合を回避。
   - 物理 Ⓑ ボタン（Joypad Button 1）で気持ちよくボール発射・UI決定が可能。
8. **リッチなプロシージャル演出 & SE**:
   - 外部音声ファイル不要の **プロシージャル効果音生成 (SoundManager.gd)**（爆発音・レベルアップファンファーレ・ドローン被弾音等）。
   - ブロック破壊時のカラー破片パーティクル (`CPUParticles2D`) と画面シェイク (`Camera2D`)。
9. **マルチ操作対応 (ハイブリッド)**:
   - **ゲームパッド/物理ボタン**: 十字キー/スティック + Ⓑボタン発射
   - **PCキーボード**: A/D または 左右矢印 + Space/Enterキー
   - **画面タッチ**: 画面上ドラッグ移動 + タッチ発射ボタン

## 🛠️ Godotでの開き方 & プレイ方法

1. **Godot Engine 4.x** (4.2 / 4.3 / 4.7) を起動します。
2. プロジェクトマネージャーで **「インポート (Import)」** をクリック。
3. 本リポジトリのフォルダ（`project.godot` がある場所）を選択して開きます。
4. 右上の **「実行 (Play)」** ボタン（または `F5`）を押すと、すぐにゲームが始まります。

## 📱 Android端末へのエクスポート (APKビルド) 手順

### 1. 前提条件の準備 (初回のみ)
* Android SDK および OpenJDK (JDK 17) がPCにインストールされていること。
* Godotのエディタ設定 (`エディタ` -> `エディタ設定` -> `エクスポート` -> `Android`) で以下を指定：
  * **Android SDKパス**: `C:/Users/<ユーザー名>/AppData/Local/Android/Sdk` など
  * **Debug Keystoreパス**: `debug.keystore` の場所

### 2. APKのエクスポート
1. Godotエディタで `プロジェクト` -> `エクスポート` を開きます。
2. プリセット一覧に **`Android_godot_test`** が登録されています。
3. 下部の **「プロジェクトのエクスポート (Export Project)」** をクリックし、任意の場所に `.apk` ファイルを保存します。
4. コマンドラインから直接ビルドする場合：
   ```powershell
   godot --headless --export-debug "Android_godot_test" BreakoutRetro.apk
   ```
5. ADB 経由で実機へインストールして起動：
   ```powershell
   adb install -r BreakoutRetro.apk
   adb shell monkey -p com.godottest.breakoutretro -c android.intent.category.LAUNCHER 1
   ```

## 💡 技術解説：Android「Bボタン問題」をGodotでどう解決したか？

### 課題：なぜAndroidゲーム機でBボタンが「戻る」になってしまうのか？
Android OSでは、一般的なゲームパッドの「Bボタン」や一部のキーコードがシステム標準の `KEYCODE_BACK`（戻るキー）としてOSレベルで割り当てられていることがあります。そのため、通常のWebアプリやWebViewアプリでは「Bボタンを押した瞬間にゲームが終了する／前画面に戻る」という現象が発生します。

### Godot 4 による解決アプローチ：
1. **Joypad Button 1の直接マッピング (`project.godot`)**:
   GodotはAndroidのゲームパッド入力をSDL2/NDKレイヤーでネイティブにフックし、`JoypadButton` (Button Index 1) としてゲームエンジン内部の入力イベントキューに振り分けます。
2. **Input Map でのアクション抽象化**:
   `launch_ball` アクションに `JoypadButton(index=1)` (Bボタン)、`JoypadButton(index=0)` (Aボタン)、`Key(Space)` を一括バインドすることで、どの入力ソースからでも同一のGDScript処理を実行可能にしました。
3. **OS Backイベントの安全なハンドリング (`Game.gd`)**:
   `get_tree().set_auto_accept_quit(false)` と `NOTIFICATION_WM_GO_BACK_REQUEST` を適切に処理することで、Backイベントが発生してもアプリが強制終了せず、ゲーム内のポーズやリトライ等の適切なアクションとして吸収されます。
